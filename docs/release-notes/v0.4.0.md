Open CAM Studio v0.4.0 adds 3D Spiral finishing and improves model positioning,
desktop preferences and toolpath generation.

## New

- **3D Spiral finishing** generates projected spiral or concentric-circle surface
  passes with controls for center, boundary, stepover, direction and depth.
- **Model and body positioning** adds viewport translation and rotation controls,
  exact values, previews and undo for imported CAD geometry.
- **Tabbed Preferences and local desktop MCP** make application settings and
  connecting an MCP client to the running desktop session easier to manage.
- **Open-profile tangential extensions** extend the ends of open profiles to help
  guide tool entry and exit.

## Changed and fixed

- Improved 3D Adaptive Clearing paths and arc linking, including a fix for thin
  stock spikes in simulation.
- Improved 3D Parallel containment and transitions between cutting passes.
- Fixed CAD pocket boundary handling and concentric clearing coverage; concentric
  pockets now use the specified maximum stepover.
- Fixed rounded corners on open profiles and simulated profile wall reconstruction.
- Improved workspace editing and project-tree controls.
